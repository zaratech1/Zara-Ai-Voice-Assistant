Privacy

Conversations and settings are stored in data/zara.db on this computer. Audio is not saved. The microphone is active only while listening or when the optional wake word is enabled. AI conversations go only to the configured local server.

Use each conversation’s menu to delete its history.

About ZARA

A Windows desktop voice assistant built with Python, Eel, and SQLite.

Commands run through a controlled router. Conversational answers use an optional local AI server.
